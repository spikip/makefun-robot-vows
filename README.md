## About this entry

A robot wedding vow has to do two things at once: sound like a real vow a
couple would say at an altar, and break down in a way only a machine could.
This entry keeps the classic shape of the ceremony - "I take you" and a
list of paired conditions, the robot answer to richer and poorer, sickness
and health. The conditions are all drawn from a machine's actual life:
being fully charged or down to the last percent of battery, running in
focus or stuck booting into safe mode. Then the promise itself lands at
the end, where the judge brief wants the payoff: no update will ever
change how I feel about you. For a robot that is the deepest commitment
there is, because an update is the one thing that can rewrite a machine's
personality overnight - feelings included. Promising to refuse that update
forever is a robot saying its love is not a setting that can be patched.
The line stays deadpan, reads aloud in one breath like something an
officiant would nod through, and fits the 160 character cap with room to
spare. The program just holds the vow, checks its length, and writes it
to /output/entry.txt exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one-line vow to `/output/entry.txt`.
